## 주요 기능

- **촬영일별 정리**: 영상마다 있는 XML의 촬영 시작 시각으로 날짜 폴더를 만듭니다.
- **종류별 분리**: 원본 영상, 프록시, 사진(JPG·ARW·HIF)을 날짜 폴더 안에서 따로 모읍니다.
- **프록시 바로 연결**: `SUB` 폴더의 프록시를 날짜 폴더 안의 `Proxy` 폴더로 옮기고, 이름을 `_Proxy.MP4`로 바꿉니다. Premiere에서 바로 프록시로 연결할 수 있습니다.
- **겹치는 파일 이름 알림**: 카드마다 C0001부터 다시 시작하는 번호가 겹치면, 정리하기 전에 알려 줍니다.
- **폴더 용량 표기**: 날짜 폴더 이름 끝에 용량을 붙입니다. 백업본과 용량을 비교할 때 참고할 수 있습니다.
- **미리보기**: [정리 시작]을 누르기 전에 결과를 먼저 보여 줍니다.
- **안전한 정리**: 영상·사진을 지우지 않고 옮기기만 합니다. 덮어쓰지 않고, [되돌리기]가 있습니다.
- **간단한 설치**: 관리자 권한 없이 설치하고 제거합니다. 인터넷에 연결하지 않습니다.

## 만든 이유

7년 동안 영상을 만들면서 촬영보다 더 지치는 일이 있었어요. 촬영이 끝나고 카드 데이터를 정리하는 일이에요. 😅

촬영일을 확인하려고 XML을 열고, `SUB` 폴더에서 프록시를 찾아 이름을 바꾸고, 날짜별로 폴더를 만들고…
매번 같은 일을 손으로 반복했어요. 그러다 한 번 실수하면 파일을 찾느라 시간을 더 쓰게 되고요.

  <img src="assets/readme/how.jpg" width="680" alt="뒤섞인 카드 파일이 날짜 폴더로 깔끔하게 나뉘는 모습">
</p>

그래서 제가 현장에서 쓰던 정리 기준을 그대로 프로그램에 담았어요.
이제는 복사한 폴더를 끌어다 놓고 [정리 시작]만 누르면 끝나요.

**이런 고민을 풀었어요**

- **영상 파일 이름(C0001)에 날짜가 없어서, XML을 열어 봐야 촬영일을 알 수 있었어요.**
  → XML의 촬영 시작 시각을 읽어서 날짜 폴더로 나눠 드려요.
- **프록시가 `M4ROOT\SUB` 깊숙이, 다른 이름으로 들어 있었어요.**
  → 원본 영상과 같은 날짜 폴더로 옮기고 `_Proxy.MP4`로 바꿔요. Premiere에서 바로 연결돼요.
- **카드마다 번호가 C0001부터 다시 시작해서 이름이 자꾸 겹쳤어요.**
  → 같은 이름은 덮어쓰지 않아요. 정리하기 전에 겹치는 파일을 먼저 알려 드려요.
- **카드를 포맷하고 나면 백업이 다 됐는지 확인하기 어려웠어요.**
  → 날짜 폴더 이름 끝에 용량을 붙여요. 백업본과 용량을 비교할 때 참고하면 돼요.
- **손으로 옮기다 덮어쓰거나 잃어버릴까 늘 불안했어요.**
  → 끝나면 옮긴 파일을 하나씩 확인하고, [되돌리기]로 정리 전 위치로 돌릴 수 있어요.

**돈보다 나눔을 위해 만들었어요**

이 프로그램으로 돈을 벌 생각은 없어요.
영상 만드는 분들이 정리 시간을 아껴서, 그 시간을 촬영과 편집에 쓰시면 좋겠어요.
소스 코드도 MIT 라이선스로 모두 공개했어요.

개발은 AI 도구 Claude와 함께 했어요.
하지만 무엇을 어디로 정리할지, 어디까지 안전하게 지킬지는 7년 동안 직접 부딪히며 정한 기준이에요.

써 보시고 좋았던 점이나 불편한 점을 유튜브 채널 [이중필름](https://www.youtube.com/@2J_FILM)이나 메일로 편하게 알려 주세요. 🙌

## 사용법

> [!CAUTION]
> **Premiere로 가져오기 전에 정리하세요.**
> [날짜 폴더 이름에 용량 붙이기] 옵션이 켜져 있으면 정리할 때마다 날짜 폴더 이름이 바뀝니다.
> 가져온 뒤에 같은 날짜를 다시 정리하면, Premiere에서 링크를 다시 연결해야 합니다.

> [!WARNING]
> **카드 데이터를 PC로 복사한 뒤, 복사한 폴더만 정리하세요.**
> 카드를 바로 정리하면 되살릴 복사본이 없습니다.

1. 카드 데이터를 카드마다 새 PC 폴더에 복사하세요.
   카드 전체, `M4ROOT` 폴더, 영상과 XML만 복사해도 됩니다.
2. SONY 타입 정리기를 여세요.
3. 복사한 폴더를 창에 끌어다 놓으세요.
   또는 [폴더 선택…]을 누르고 복사한 폴더를 고르세요.
4. 미리보기 표를 확인하세요. [정리 시작]을 누르기 전에는 프로그램이 파일을 옮기지 않습니다.
5. [정리 시작]을 누르세요.
6. 결과 요약을 확인하세요.
7. 결과가 마음에 들지 않으면 [되돌리기]를 누르세요.

> [!WARNING]
> **결과를 확인하기 전에는 카드를 포맷하지 마세요. 백업본도 지우지 마세요.**
> 백신, 동기화 프로그램, 저장 장치가 파일 옮기기를 막을 수 있습니다.

**우클릭으로 열기**: 탐색기에서 복사한 폴더를 우클릭하고 [SONY 타입 정리기로 정리]를 누르세요.
프로그램이 그 폴더를 넣은 상태로 열립니다. 그다음 4번부터 하세요.
Windows 11에서는 [더 많은 옵션 표시]를 먼저 누르세요.

## 정리 결과

```
복사한 폴더
└ 261004_DATA_29.5G                 ← 날짜 폴더. 이름 끝은 용량 (옵션)
   ├ 261004_Footage    원본 영상     C0561.MP4
   ├ 261004_Proxy      프록시        C0561_Proxy.MP4        ← M4ROOT\SUB\C0561S03.MP4
   ├ 261004_XML        메타데이터    C0561M01.XML           ← XML 휴지통 옵션을 끈 경우만
   └ 261004_Photo
      ├ jpg
      ├ arw
      └ hif
```

**날짜 폴더 이름 끝의 용량**

- 용량은 1GB 이상이면 `_29.5G`, 1GB 미만이면 `_412M` 형식입니다.
- 계산 방법은 탐색기 [속성] 창과 같습니다. 1024 기준이고, 소수점 한 자리 아래는 버립니다.
- 같은 날짜를 같은 폴더에서 나중에 정리하면, 프로그램이 기존 날짜 폴더에 합칩니다. 그리고 용량을 새로 계산합니다.

## 카드에 맞춘 규칙

| 소니 카드의 특징 | 정리 방법 |
|---|---|
| 영상 파일 이름(C0001)에 날짜가 없음 | 짝인 XML(`C0001M01.XML`)의 촬영 시작 시각으로 촬영일을 정함. 시간대는 카메라 설정 그대로. XML이 없으면 파일의 수정한 날짜를 씀 |
| 자정을 넘겨 촬영함 | 촬영을 시작한 날의 날짜 폴더에 넣음 |
| 프록시는 `SUB\원본 영상 이름S03.MP4` | 원본 영상과 같은 날짜 폴더에 넣음. 이름은 `원본 영상 이름_Proxy.MP4`. Premiere에서 바로 프록시로 연결됨 |
| S&Q(슬로·퀵모션) 영상은 프록시가 생기지 않음 | XML로 찾아서 미리보기에서 "프록시가 없는 원본"으로 알림 |
| 파일 번호가 카드마다 C0001부터 다시 시작함 | 같은 이름이 있으면 덮어쓰지 않고 건너뜀. 미리보기에서 먼저 알림 |
| 기종에 따라 `M4ROOT` 또는 `PRIVATE\M4ROOT`를 씀 | 두 곳을 모두 찾음 |
| `M4ROOT\THMBNL`의 JPG는 영상 썸네일임 | 사진과 섞지 않음 |
| 파일 이름 앞부분을 바꾼 카메라가 있음 (예: `A7V_0001`) | XML·프록시 짝을 이름으로 맞춤 |

넣을 수 있는 폴더: 카드 전체를 복사한 폴더, `M4ROOT` 폴더, 영상과 XML만 모은 폴더

- 파일만 모은 폴더에서는 3종류만 소니 파일로 봅니다: 짝인 XML이 있는 MP4, 소니 이름(`DSC…`)의 사진, ARW. 다른 파일은 그대로 둡니다.
- 옛 AVCHD(`.MTS`) 영상과 업무용 XDCAM(`.MXF`) 영상은 정리하지 않습니다. 미리보기에서 알려 줍니다.

## 옵션

프로그램이 옵션 설정을 기억합니다.

| 옵션 | 기본 | 내용 |
|---|---|---|
| XML(카메라 메타데이터)은 휴지통으로 | 켜짐 | 정리 후 XML을 휴지통으로 보냅니다. 끄면 날짜별 `XML` 폴더에 따로 모읍니다. 원본 영상을 옮기지 못한 클립의 XML은 그대로 둡니다. |
| 날짜 폴더 이름에 용량 붙이기 | 켜짐 | 날짜 폴더 이름 끝에 용량을 붙입니다. 예: `261004_DATA_29.5G` |
| 남은 카드 관리 파일도 휴지통으로 | 켜짐 | 정리 후 `M4ROOT`(썸네일 등), `PRIVATE`, `AVF_INFO`, `SONY` 폴더를 휴지통으로 보냅니다. 영상·사진이 남아 있으면 보내지 않고, 결과에 그 파일을 알려 줍니다. |

파일이 하나도 없는 카드 폴더는 옵션과 상관없이 지웁니다. 예: 사진을 찍지 않은 카드의 빈 `DCIM\100MSDCF`

## 안전장치

- **영상·사진 파일을 지우지 않습니다.** 프로그램은 복사한 폴더 안에서 파일을 옮기기만 합니다. 그래서 용량이 커도 빨리 끝납니다.
- **덮어쓰지 않습니다.** 같은 이름의 파일이 있으면 프로그램이 그 파일을 건너뜁니다.
- **결과를 확인합니다.** 정리가 끝나면 옮긴 파일이 모두 제자리에 같은 크기로 있는지 하나씩 확인합니다.
- **카드를 바로 정리하지 않습니다.** 카드 안의 폴더를 넣으면 PC로 복사하라고 안내합니다.
- **시스템 보조 파일만 남은 폴더는 지웁니다.** 대상 파일은 `Thumbs.db`, `desktop.ini`, `.DS_Store`, `._파일이름`, `@eaDir`입니다. 영상·사진은 대상이 아닙니다. 그래서 정리 후 빈 `DCIM` 폴더가 남지 않습니다.
- **인터넷에 연결하지 않습니다.** 어떤 정보도 수집하지 않습니다.

</details>

<details>
<summary><b>카드 두 장을 같은 폴더에 복사해도 되나요?</b></summary>

카드마다 다른 폴더에 복사하세요. 소니 카메라는 카드마다 파일 번호를 C0001부터 다시 매깁니다.
같은 폴더에 복사하면 이름이 겹쳐 일부 파일을 정리하지 못합니다. 프로그램은 겹치는 파일을 덮어쓰지 않고, 미리보기에서 알려 줍니다.
</details>

<details>
<summary><b>정리를 취소하고 싶어요.</b></summary>

[되돌리기]를 누르세요. 옮긴 파일이 정리 전 위치로 돌아갑니다.
휴지통으로 보낸 XML과 카드 관리 파일은 돌아오지 않습니다. 필요하면 휴지통에서 직접 복원하세요.
</details>

<details>
<summary><b>업데이트는 어떻게 하나요?</b></summary>

새 버전의 설치 파일을 실행하고 [업데이트하기]를 누르세요. 이전 버전을 먼저 제거하지 마세요.
설정과 정리 기록은 그대로 있습니다.
</details>

<details>
<summary><b>제거는 어떻게 하나요?</b></summary>

**SONY 타입 정리기 제거.exe**를 실행하고 [제거하기]를 누르세요.
또는 [설정 › 앱 › 설치된 앱]에서 SONY 타입 정리기를 제거하세요.

제거 파일은 프로그램, 바로가기, 우클릭 메뉴, 설정, 정리 기록을 지웁니다. 정리한 영상·사진 폴더는 지우지 않습니다.
</details>

<details>
<summary><b>설정과 기록은 어디에 저장되나요?</b></summary>

설정과 정리 기록은 `%LOCALAPPDATA%\SonySortTool`에 저장합니다.
예상하지 못한 오류가 나면 같은 폴더의 `logs\error_….txt`에 오류 기록을 저장합니다. 문의할 때 이 파일을 첨부하세요.
</details>
