# SONY 타입 정리기 (베타)

![SONY 타입 정리기](assets/art/hero.png)

소니 카메라로 찍은 영상·프록시·사진을 촬영일별 날짜 폴더로 정리하는 Windows용 무료 프로그램입니다.
7년 동안 영상을 만들며 쓴 데이터 정리 기준을 그대로 담았습니다.
복사한 폴더를 창에 끌어다 놓고 [정리 시작]을 누르세요.

> [!NOTE]
> **Sony(소니)가 만든 정식 프로그램이 아닙니다.** 개인(이중필름)이 만든 비공식 무료 프로그램입니다. Sony와 관련이 없습니다.
> 'SONY 타입'은 소니 카메라가 만드는 카드 구조를 정리한다는 뜻입니다.
> Sony는 Sony Group Corporation의 상표입니다.

> 1.5 베타 · 만든 사람: 이중필름 (유튜브 채널 **[이중필름](https://www.youtube.com/@2J_FILM)**) · 문의: nasunfilm@gmail.com · 비영리 무료 배포

> [!WARNING]
> **카드 데이터를 PC로 복사한 뒤, 복사한 폴더만 정리하세요.**
> 이 프로그램은 카드를 바로 정리하도록 만들지 않았습니다. 카드를 바로 정리하면 되살릴 복사본이 없습니다.

## 만든 이유

7년 동안 영상을 만들면서 촬영보다 더 지치는 일이 있었어요. 촬영이 끝나고 카드 데이터를 정리하는 일이에요. 😅

촬영일을 확인하려고 XML을 열고, `SUB` 폴더에서 프록시를 찾아 이름을 바꾸고, 날짜별로 폴더를 만들고…
매번 같은 일을 손으로 반복했어요. 그러다 한 번 실수하면 파일을 찾느라 시간을 더 쓰게 되고요.

그래서 제가 현장에서 쓰던 정리 기준을 그대로 프로그램에 담았어요.
이제는 복사한 폴더를 끌어다 놓고 [정리 시작]만 누르면 끝나요.

**이런 고민을 풀었어요**

- **영상 파일 이름(C0001)에 날짜가 없어서, XML을 열어 봐야 촬영일을 알 수 있었어요.**
  → XML의 촬영 시작 시각을 읽어서 날짜 폴더로 나눠 드려요.
- **프록시가 `M4ROOT\SUB` 깊숙이, 다른 이름으로 들어 있었어요.**
  → 원본 영상과 같은 날짜 폴더로 옮기고 `_Proxy.MP4`로 바꿔요. Premiere에서 바로 연결돼요.
- **카드마다 번호가 C0001부터 다시 시작해서 이름이 자꾸 겹쳤어요.**
  → 같은 이름은 덮어쓰지 않아요. 정리하기 전에 겹치는 파일을 먼저 알려 드려요.
- **카드를 포맷하고 나면 백업이 다 됐는지 확인하기 어려웠어요.**
  → 날짜 폴더 이름 끝에 용량을 붙여요. 백업본과 숫자만 비교하면 돼요.
- **손으로 옮기다 덮어쓰거나 잃어버릴까 늘 불안했어요.**
  → 끝나면 하나씩 확인하고, [되돌리기]로 언제든 정리 전으로 돌아가요.

**돈보다 나눔을 위해 만들었어요**

이 프로그램으로 돈을 벌 생각은 없어요.
영상 만드는 분들이 정리 시간을 아껴서, 그 시간을 촬영과 편집에 쓰시면 좋겠어요.
소스 코드도 MIT 라이선스로 모두 공개했어요.

개발은 AI 도구 Claude와 함께 했어요.
하지만 무엇을 어디로 정리할지, 어디까지 안전하게 지킬지는 7년 동안 직접 부딪히며 정한 기준이에요.

써 보시고 좋았던 점이나 불편한 점을 유튜브 채널 [이중필름](https://www.youtube.com/@2J_FILM)이나 메일로 편하게 알려 주세요. 🙌

## 내려받기·설치

Windows 10과 11에서 씁니다. 관리자 권한은 필요 없습니다.

1. [Releases](https://github.com/musiqsb-svg/sony-sort-tool/releases)에서 `SonySortTool-1.5.zip`을 내려받으세요.
2. zip 파일의 압축을 푸세요. 파일 3개가 나옵니다.

   | 파일 | 하는 일 |
   |---|---|
   | **SONY 타입 정리기 설치.exe** | 설치 파일. 설치와 업데이트를 합니다. |
   | **SONY 타입 정리기 제거.exe** | 제거 파일. 프로그램을 제거합니다. |
   | 사용 안내.txt | 설치·사용·제거 방법 |

3. **SONY 타입 정리기 설치.exe**를 실행하세요.
4. 파란 "Windows의 PC 보호" 창이 뜨면 [추가 정보]를 누르세요. 창이 뜨지 않으면 6번으로 가세요.
5. [실행]을 누르세요. [실행 안 함]을 누르면 설치 파일이 열리지 않습니다.

   ![Windows의 PC 보호 창: ① 추가 정보 → ② 실행](assets/guide/smartscreen.png)

6. 필요 없는 항목은 스위치를 끄세요: [바탕화면 아이콘], [폴더 우클릭 메뉴]
7. [설치하기]를 누르세요. 이전 버전이 있으면 이 버튼 이름은 [업데이트하기]입니다.

"Windows의 PC 보호" 창은 코드 서명 인증서(유료)가 없는 프로그램에 뜹니다.
받은 파일이 배포한 파일과 같은지 확인하려면, 릴리스 글의 파일 지문(SHA256)과 비교하세요.

**설치하면 생기는 것**

- 시작 메뉴: SONY 타입 정리기
- 바탕화면 아이콘 (선택)
- 폴더 우클릭 메뉴: [SONY 타입 정리기로 정리] (선택)
- [설정 › 앱 › 설치된 앱]의 제거 항목

**업데이트**

- 이전 버전이 있어도 먼저 제거하지 마세요. 설치 파일이 그 위에 업데이트합니다.
- 업데이트해도 설정과 정리 기록은 그대로 있습니다.

### 제거

1. **SONY 타입 정리기 제거.exe**를 실행하세요.
   또는 [설정 › 앱 › 설치된 앱]에서 SONY 타입 정리기를 제거하세요.
2. [제거하기]를 누르세요.

제거 파일은 프로그램, 바로가기, 우클릭 메뉴, 설정, 정리 기록을 지웁니다.
정리한 영상·사진 폴더는 지우지 않습니다.

## 사용법

> [!CAUTION]
> **Premiere로 가져오기 전에 정리하세요.**
> [날짜 폴더 이름에 용량 붙이기] 옵션이 켜져 있으면 정리할 때마다 날짜 폴더 이름이 바뀝니다.
> 가져온 뒤에 같은 날짜를 다시 정리하면, Premiere에서 링크를 다시 연결해야 합니다.

1. 카드 데이터를 PC 폴더로 복사하세요.
   카드마다 다른 폴더에 복사하세요. 소니 카메라는 카드마다 파일 번호를 C0001부터 다시 매깁니다.
2. SONY 타입 정리기를 여세요.
3. 복사한 폴더를 창에 끌어다 놓으세요.
   또는 [폴더 선택…]을 누르고 복사한 폴더를 고르세요.
4. 미리보기 표를 확인하세요. [정리 시작]을 누르기 전에는 프로그램이 파일을 옮기지 않습니다.
5. [정리 시작]을 누르세요.
6. 결과 요약을 확인하세요.
7. 결과가 마음에 들지 않으면 [되돌리기]를 누르세요.

> [!WARNING]
> **결과를 확인하기 전에는 카드를 포맷하지 마세요. 백업본도 지우지 마세요.**
> 백신, 동기화 프로그램, 저장 장치가 파일 옮기기를 막을 수 있습니다.

**우클릭으로 열기**: 탐색기에서 복사한 폴더를 우클릭하고 [SONY 타입 정리기로 정리]를 누르세요.
프로그램이 그 폴더를 넣은 상태로 열립니다. 그다음 4번부터 하세요.
Windows 11에서는 [더 많은 옵션 표시]를 먼저 누르세요.

## 정리 결과

```
복사한 폴더
└ 261004_DATA_29.5G                 ← 날짜 폴더. 이름 끝은 용량 (옵션)
   ├ 261004_Footage    원본 영상     C0561.MP4
   ├ 261004_Proxy      프록시        C0561_Proxy.MP4        ← M4ROOT\SUB\C0561S03.MP4
   ├ 261004_XML        메타데이터    C0561M01.XML           ← XML 휴지통 옵션을 끈 경우만
   └ 261004_Photo
      ├ jpg
      ├ arw
      └ hif
```

**날짜 폴더 이름 끝의 용량**

- 용량은 1GB 이상이면 `_29.5G`, 1GB 미만이면 `_412M` 형식입니다.
- 계산 방법은 탐색기 [속성] 창과 같습니다. 1024 기준이고, 소수점 한 자리 아래는 버립니다.
- 카드를 포맷한 뒤에도 NAS·외장하드 백업본과 용량을 비교할 수 있습니다.
- 같은 날짜를 같은 폴더에서 나중에 정리하면, 프로그램이 기존 날짜 폴더에 합칩니다. 그리고 용량을 새로 계산합니다.

## 카드에 맞춘 규칙

| 소니 카드의 특징 | 정리 방법 |
|---|---|
| 영상 파일 이름(C0001)에 날짜가 없음 | 짝인 XML(`C0001M01.XML`)의 촬영 시작 시각으로 촬영일을 정함. 시간대는 카메라 설정 그대로. XML이 없으면 파일의 수정한 날짜를 씀 |
| 프록시는 `SUB\원본 영상 이름S03.MP4` | 원본 영상과 같은 날짜 폴더에 넣음. 이름은 `원본 영상 이름_Proxy.MP4`. Premiere에서 바로 프록시로 연결됨 |
| S&Q(슬로·퀵모션) 영상은 프록시가 생기지 않음 | XML로 찾아서 미리보기에서 "프록시가 없는 원본"으로 알림 |
| 파일 번호가 카드마다 C0001부터 다시 시작함 | 같은 이름이 있으면 덮어쓰지 않고 건너뜀. 미리보기에서 먼저 알림 |
| 기종에 따라 `M4ROOT` 또는 `PRIVATE\M4ROOT`를 씀 | 두 곳을 모두 찾음 |
| `M4ROOT\THMBNL`의 JPG는 영상 썸네일임 | 사진과 섞지 않음 |
| 파일 이름 앞부분을 바꾼 카메라가 있음 (예: `A7V_0001`) | XML·프록시 짝을 이름으로 맞춤 |

넣을 수 있는 폴더: 카드 전체를 복사한 폴더, `M4ROOT` 폴더, 영상과 XML만 모은 폴더

- 파일만 모은 폴더에서는 3종류만 소니 파일로 봅니다: 짝인 XML이 있는 MP4, 소니 이름(`DSC…`)의 사진, ARW. 다른 파일은 그대로 둡니다.
- 옛 AVCHD(`.MTS`) 영상과 업무용 XDCAM(`.MXF`) 영상은 정리하지 않습니다. 미리보기에서 알려 줍니다.

## 옵션

프로그램이 옵션 설정을 기억합니다.

| 옵션 | 기본 | 내용 |
|---|---|---|
| XML(카메라 메타데이터)은 휴지통으로 | 켜짐 | 정리 후 XML을 휴지통으로 보냅니다. 끄면 날짜별 `XML` 폴더에 따로 모읍니다. 원본 영상을 옮기지 못한 클립의 XML은 그대로 둡니다. |
| 날짜 폴더 이름에 용량 붙이기 | 켜짐 | 날짜 폴더 이름 끝에 용량을 붙입니다. 예: `261004_DATA_29.5G` |
| 남은 카드 관리 파일도 휴지통으로 | 켜짐 | 정리 후 `M4ROOT`(썸네일 등), `PRIVATE`, `AVF_INFO`, `SONY` 폴더를 휴지통으로 보냅니다. 영상·사진이 남아 있으면 보내지 않고, 결과에 그 파일을 알려 줍니다. |

파일이 하나도 없는 카드 폴더는 옵션과 상관없이 지웁니다. 예: 사진을 찍지 않은 카드의 빈 `DCIM\100MSDCF`

## 안전장치

- **영상·사진 파일을 지우지 않습니다.** 프로그램은 복사한 폴더 안에서 파일을 옮기기만 합니다. 그래서 용량이 커도 바로 끝납니다.
- **[되돌리기]로 정리 전 위치에 되돌릴 수 있습니다.** 휴지통으로 보낸 XML과 카드 관리 파일은 휴지통에서 직접 복원하세요.
- **덮어쓰지 않습니다.** 같은 이름의 파일이 있으면 프로그램이 그 파일을 건너뜁니다.
- **결과를 확인합니다.** 정리가 끝나면 옮긴 파일이 모두 제자리에 같은 크기로 있는지 하나씩 확인합니다.
- **카드를 바로 정리하지 않습니다.** 카드 안의 폴더를 넣으면 PC로 복사하라고 안내합니다.
- **찌꺼기 파일만 남은 폴더는 지웁니다.** 찌꺼기 파일은 `Thumbs.db`, `desktop.ini`, `.DS_Store`, `._파일이름`, `@eaDir`입니다. 그래서 정리 후 빈 `DCIM` 폴더가 남지 않습니다.
- **인터넷에 연결하지 않습니다.** 어떤 정보도 수집하지 않습니다.
- 설정과 정리 기록은 `%LOCALAPPDATA%\SonySortTool`에 저장합니다.
- 예상하지 못한 오류가 나면 같은 폴더의 `logs\error_….txt`에 오류 기록을 저장합니다. 문의할 때 이 파일을 첨부하세요.

## 1.5에서 바뀐 점

- 화면과 설치 파일에 "Sony 정식 프로그램이 아닙니다"를 표시함
- **배포 파일을 zip 하나로 바꿈.** zip에는 설치 파일, 제거 파일, 사용 안내만 있습니다. 소스 코드는 이 저장소에, 파일 지문은 릴리스 글에 있습니다.
- **설치·제거를 버튼 한 번으로 바꿈.** 관리자 권한 없이 설치하고 제거합니다.
- **화면을 새로 만듦.** 미리보기를 날짜별 표로 보여 주고, 결과를 요약 카드로 보여 줍니다.
- 작은 화면(노트북 150% 배율 등)에서도 창이 화면을 넘지 않음
- 예상하지 못한 오류를 오류 기록 파일에 저장함

## 빌드·테스트

빌드에는 Windows 10/11에 들어 있는 C# 컴파일러(.NET Framework 4.x)만 씁니다. 따로 설치할 것은 없습니다.

```
powershell -ExecutionPolicy Bypass -File build.ps1 -Test
```

| 결과 파일 | 내용 |
|---|---|
| `dist\SonySortTool.exe` | 프로그램. 설치하지 않아도 실행됩니다. |
| `dist\Setup.exe` | 설치 파일. 배포 이름은 `SONY 타입 정리기 설치.exe` |
| `dist\Uninstall.exe` | 제거 파일. 배포 이름은 `SONY 타입 정리기 제거.exe` |
| `build\OrganizerTest.exe` | 정리 로직 테스트. 실제 카드(ILCE-7M5) 구조를 본뜬 가짜 카드로 여러 상황을 시험합니다. |
| `tests\SetupTest.ps1` | 설치·제거 테스트 |

`OrganizerTest.exe --replica <폴더>`는 실제 카드 폴더의 복제본으로 시험합니다.
복제본에서 XML은 내용까지 복사하고, 다른 파일은 1바이트로 만듭니다. 원본 폴더는 바뀌지 않습니다.

설치·제거 테스트는 임시 폴더와 별도 레지스트리 키(`/sandbox`)만 씁니다.
그래서 테스트해도 PC에 설치된 프로그램은 바뀌지 않습니다.
테스트 항목: 새로 설치, 다시 설치, 이전 버전 업데이트, 실행 중 설치 막기, 제거

배포 파일을 만들려면 `-Release`를 붙이세요.
버전은 두 곳에 씁니다: `src\Product.cs`의 `Version`, `src\app.manifest`

```
powershell -ExecutionPolicy Bypass -File build.ps1 -Release
```

```
release\
├ SonySortTool-1.5.zip      ← 배포 파일. GitHub 릴리스에 이 파일만 올림

└ SHA256.txt                ← 파일 지문. 릴리스 글에 붙임
```
