SONY 타입 정리기 {VERSION} (베타)
소니 카메라로 찍은 영상·프록시·사진을 촬영일별 날짜 폴더로 정리하는 Windows 무료 프로그램입니다.

※ Sony(소니)가 만든 정식 프로그램이 아닙니다. 개인(이중필름)이 만든 비공식 프로그램입니다.
   Sony와 관련이 없습니다.

7년 동안 영상을 만들며 쓴 데이터 정리 기준을 그대로 담았습니다.
돈을 벌려고 만들지 않았습니다. 영상을 만드는 누구나 정리 시간을 줄이도록 무료로 나눕니다.


■ 설치

  1. 'SONY 타입 정리기 설치.exe'를 실행하세요.
  2. "Windows의 PC 보호" 창이 뜨면 [추가 정보]를 누르세요.
  3. [실행]을 누르세요.
  4. [설치하기]를 누르세요.

  · 관리자 권한은 필요 없습니다.
  · 이전 버전이 있으면 업데이트합니다. 설정과 정리 기록은 그대로 있습니다.
  · "Windows의 PC 보호" 창은 코드 서명 인증서가 없는 무료 프로그램에 뜹니다.


■ 사용

  경고: 카드 데이터를 PC로 복사한 뒤, 복사한 폴더만 정리하세요.

  1. 카드 데이터를 PC 폴더로 복사하세요. 카드마다 다른 폴더에 복사하세요.
  2. SONY 타입 정리기를 여세요.
  3. 복사한 폴더를 창에 끌어다 놓으세요.
     또는 폴더를 우클릭하고 'SONY 타입 정리기로 정리'를 누르세요.
     Windows 11에서는 '더 많은 옵션 표시'를 먼저 누르세요.
  4. 미리보기를 확인하세요.
  5. [정리 시작]을 누르세요.
  6. 결과가 마음에 들지 않으면 [되돌리기]를 누르세요.

  경고: 결과를 확인하기 전에는 카드를 포맷하지 마세요. 백업본도 지우지 마세요.

  복사한 폴더
  └ 261004_DATA_29.5G           ← 날짜 폴더 (촬영일 + 용량)
     ├ 261004_Footage           원본 영상
     ├ 261004_Proxy             프록시
     └ 261004_Photo\jpg, arw, hif

  · 프록시는 Premiere에서 바로 연결됩니다.
  · 소니 카메라는 카드마다 파일 번호를 C0001부터 다시 매깁니다.
    그래서 카드마다 다른 폴더에 정리하세요.


■ 제거

  1. 'SONY 타입 정리기 제거.exe'를 실행하세요.
     또는 [설정 › 앱 › 설치된 앱]에서 SONY 타입 정리기를 제거하세요.
  2. [제거하기]를 누르세요.

  · 정리한 영상·사진 폴더는 그대로 있습니다.
